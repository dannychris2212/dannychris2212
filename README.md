## 📝 Liner notes: how I work

- **Start from the real problem.** Every project here began as something that was annoying me or someone I work with.
- **Debug layer by layer.** When something breaks, I find the layer where it actually broke before I fix anything.
- **Write down the why.** Decisions are more useful than code: they're what the next person (or me, in six months) needs.
- **Ship, then iterate.** A working version in front of users beats a perfect one in my head.
